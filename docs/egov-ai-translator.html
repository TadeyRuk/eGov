Translator capabilities

Ang Translator ay isang text-transformation capability para gawing mas accessible ang government information sa iba't ibang wika. Tumatanggap ito ng source text at language codes, pagkatapos ay nagbabalik ng translated text.

Interface: HTTPS + JSON Authentication: Bearer token Category: Translation Review: Required for critical content
Scope summary

Prompt-based translation ito. Hindi ito automatic publishing system, legal certification service, o partner-controlled model-training API.

Core capabilities

01

Direct text translation

Magsalin ng announcements, instructions, FAQs, labels, at service descriptions mula source language patungo sa target language.

02

Citizen-service localization

Gumawa ng multilingual versions ng public-service content para sa web, mobile, kiosk, email, o help-desk workflow.

03

Form guidance

Isalin ang form labels, documentary requirements, status messages, at next-step instructions.

04

Document-text translation

Isalin ang permitted text na nakuha muna sa Document Extractor o ibang approved OCR workflow.

05

Multilingual support replies

Tulungan ang service desk na maghanda ng sagot sa wikang mas madaling maunawaan ng citizen.

06

Language metadata

Gamitin ang source at target language codes upang gawing predictable ang translation request at response handling.

API contract

Ang kasalukuyang hackathon request ay gumagamit ng translation endpoint sa ibaba. Panatilihin ang access token sa backend; huwag ilagay ito sa browser HTML o client-side JavaScript.

POST/api/v1/egov/integration/translator/generate

Request example

Authorization: Bearer <server-side-token>
Content-Type: application/json

{
  "prompt": "Your appointment is confirmed.",
  "source_lang": "en",
  "target_lang": "fil"
}

Conceptual response

{
  "data": "Kumpirmado na ang iyong appointment.",
  "source_lang": "en",
  "target_lang": "fil"
}

Ang eksaktong response fields at supported language codes ay dapat kumpirmahin sa current dashboard contract bago i-hard-code.

Recommended workflow

1. Validate input
2. Call backend
3. Translate
4. Human review
5. Publish
  • Validate source text, length, and approved language codes.
  • Remove personal data that is not required for translation.
  • Preserve dates, amounts, reference numbers, and official names.
  • Compare high-impact translations against the original text.
  • Record the source version and review status when publishing official content.

Limitations and safeguards

  • Hindi guaranteed na perfect ang grammar, terminology, o regional-language nuance.
  • Hindi nito pinapatunayang legally equivalent ang translated legal text.
  • Hindi dapat direktang mag-publish ng emergency, medical, eligibility, o legal instructions nang walang review.
  • Hindi dapat magpadala ng unnecessary citizen records o sensitive identifiers.
  • Hindi dapat mag-assume ng language support na wala sa official catalog.
Fail visibly

Kung unsupported ang language, incomplete ang response, o uncertain ang salin, ipakita ang review/error state sa halip na maglabas ng translation na parang verified.
